# 📊 Employee Performance & Compensation Analysis

## 📌 Project Overview
This project focuses on analyzing employee performance and compensation data using Microsoft Excel. It helps explore workforce trends, evaluate employee performance, and understand compensation patterns through structured analysis and interactive dashboards.

## 🎯 Project Objectives
- Analyze employee performance metrics.
- Explore employee compensation and bonus distributions.
- Identify trends across cities and managers.
- Summarize key workforce insights using PivotTables.
- Present findings through an Excel dashboard.

## 🗂️ Project Workbook
**File:** `Employee_Performance_Compensation_Analysis.xlsx`

The workbook includes the following sheets:
- **EMPLOYEES:** Employee dataset.
- **ANSWERS:** Analysis questions and answers.
- **PIVOT TABLES:** Summarized data and pivot analysis.
- **DASHBOARD:** Visual representation of key insights.
- **MANAGERS:** Manager-related information.
- **CITY_BONUS:** City and bonus-related information.

## 🛠️ Tools & Skills
- Microsoft Excel
- Data Cleaning and Data Analysis
- PivotTables
- Data Visualization
- Dashboard Development
- Business Reporting

## 📈 Business Questions
- What insights can be derived from employee performance?
- How does compensation vary across employees?
- How are bonuses distributed across cities?
- What patterns can be identified across managers?
- Which workforce metrics deserve further investigation?

## 🚀 How to Use
1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel.
3. Explore the individual worksheets.
4. Review the PivotTables and dashboard.
5. Use the results to understand employee and compensation trends.
